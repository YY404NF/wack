# 网络空间安全学院查课系统 `wack`

查课工作无纸化

1. 便于管理员管理整个系统，遍览查课实施动态。

2. 便于查课学生进行查课工作。

3. 便于每个班的学委进行查课工作


## 用户组

管理员：
管理整个系统

查课学生：
查当天可查的课

学委：
查当天自己所在班级的课


## 学期划分

系统自动根据当前日期及划分规则，自动填充全局学期下拉选择框的默认值
不受已经设置的开学时间影响

上半学期：每年8月1日（公历） - 每年大年三十（农历）
下半学期：每年大年初一（农历） - 每年7月31日（公历）
